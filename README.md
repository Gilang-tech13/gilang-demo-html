# To-Do List Life Dashboard

Mini project ini adalah sebuah dashboard produktivitas sederhana berbasis web yang dibuat untuk memenuhi tugas bootcamp. Dashboard ini membantu pengguna mengelola aktivitas harian dengan fitur waktu real-time, timer fokus, daftar tugas (To-Do List), dan pintasan tautan (Quick Links).

- **Live Demo (GitHub Pages):** [Masukkan Link GitHub Pages Kamu Di Sini]

## 🛠️ Teknologi yang Digunakan
- **HTML5** untuk struktur halaman
- **CSS3** untuk styling dan tata letak
- **Vanilla JavaScript (ES6)** untuk logika dan manipulasi DOM
- **Browser LocalStorage API** untuk penyimpanan data lokal

## ✨ Fitur Utama (MVP)
1. **Greeting & Jam Real-Time:** Menampilkan waktu, tanggal, dan salam otomatis sesuai waktu saat ini.
2. **Focus Timer:** Timer hitung mundur 25 menit (Pomodoro) dengan tombol Start, Stop, dan Reset.
3. **To-Do List:** Fitur tambah, edit, tandai selesai, dan hapus tugas (tersimpan di `LocalStorage`).
4. **Quick Links:** Pintasan ke situs favorit yang bisa ditambah dan dihapus (tersimpan di `LocalStorage`).

## 🎯 Pilihan Challenge yang Diimplementasikan
- [x] **Light/Dark Mode:** Fitur beralih tema tampilan terang dan gelap.
- [x] **Custom Name in Greeting:** Mengubah nama panggillan pada salam secara dinamis.
- [x] **Prevent Duplicate Tasks:** Mencegah penambahan tugas dengan nama yang sama.
